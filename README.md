# FRIZO Marketing Campaign Management Portal

A menu-driven, command-line administration system written in Python for FRIZO, a fictional fries brand ("Fries. Your Way."). Built for Programming for Business Lab, FAST-NU, section BSBA-3D.

## Features
- Products: view, add, search, update
- Campaigns: create, search, change status, delete, record performance
- Customers: register, view, search
- Promo codes: create and toggle active/inactive
- Reports: totals, click rate, conversion rate and ROMI
- Admin login with a three-attempt limit

## How to run
1. Open FRIZO_Management_Portal.ipynb in Jupyter Notebook.
2. Run all cells in order.
3. Log in with the admin credentials below and use the menu.
